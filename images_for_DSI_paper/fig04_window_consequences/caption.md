**Figure 4.** The estimation window changes the assessment. (A, B) Biomass relative to B_MSY for each functional group under seven estimation windows: the full history (start 1971), the post-1987 break, the recent window (2016), per-species windows set from research-vessel breakpoints, the Thai Department of Fisheries assessment starts, and two windows chosen by the DSIr screen (the optimum of each aggregated DOF group applied to its member species, and the optimum of each species' dominant fleet). (A) Terminal year of the fit (2023). (B) After a 20-year projection under status-quo effort (2043). Within each group the windows are offset vertically in legend order so that coincident estimates stay visible; the shaded bar spans the range across windows and the vertical line marks B = B_MSY. Two full-history projections fall below the axis range and are drawn at its edge with their values (Indian mackerel 0.017, large pelagic finfish 0.00041). (C) Estimated biomass trajectories for neritic tuna and sardines, two of the groups most sensitive to the window, drawn from each window's first modelled year; end markers identify the window. Fitting the full history forces present-day neritic tuna biomass to about 28 t, against about 195 t under the post-1987 window, because a single set of stationary parameters must reconcile the high pre-1987 abundance with the depleted recent period. The full-history and per-species trajectories of neritic tuna nearly coincide because the per-species window falls back to the 1971 start for that group. Neritic tuna shows a ridge between r and K in all windows and its absolute scale is weakly identified. Model structure is identical across windows; only the start years differ. All results use the corrected catch scaling. Projections are deterministic point estimates without intervals.
